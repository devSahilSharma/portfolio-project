## What

Owner tasks to go live properly:

- [ ] Replace all placeholder content: name, headline, bio, photo, Experience entries, social URLs, Résumé PDF.
- [ ] (When decided) Buy the domain, connect it in Cloudflare Pages, and update the site URL config.
- [ ] Add the site URL to LinkedIn, GitHub and X profiles (drives name-search ranking).
- [ ] Submit the sitemap in Google Search Console.
- [ ] Share the site link on LinkedIn/X and check the preview card renders.
